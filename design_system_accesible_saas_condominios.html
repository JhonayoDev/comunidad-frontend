Uso del Color en Pantalla (60-20-15-5)

Una correcta proporción visual del lienzo evita la fatiga del ojo del usuario (especialmente guardias, conserjes o residentes leyendo tablas financieras en la noche).

Distribución - Modo Claro

Distribución - Modo Oscuro

60% Fondo Base (Resting Eye Canvas): Controla el fondo macro de la aplicación.
20% Estructuración (Cards / Tablas): Separa bloques de información compleja.
15% Contraste de Datos (Tipografía): Títulos y cuerpo de lectura de alta legibilidad.
5% Focos Interactivos (Call to Action): Enlaces, botones primarios y acentos del sistema.

Copia de Tokens CSS para tu Equipo / IA

Copia estas declaraciones CSS en el archivo central de estilos de tu frontend para implementar de inmediato la accesibilidad.

/* ==========================================================================
   DESIGN SYSTEM ACCESIBLE (WCAG AA CONFORMANCE) - SaaS CONDOMINIOS
   ========================================================================== */

:root {
  /* MODO CLARO (Default) */
  --bg-base: #F4F4F7;
  --bg-surface: #FFFFFF;
  --text-primary: #1A1A1A;     /* Excelente contraste */
  --text-secondary: #5A5C61;   /* Corrección WCAG AA: contraste seguro de 5.9:1 */
  --border-color: #E2E2E6;
  
  --primary-color: #004D99;    /* Marca - Ratio W3C AAA de 7.8:1 */
  --primary-hover: #003366;
  
  /* Semánticos Claro */
  --status-success: #2E7D32;   /* Verde aprobado */
  --status-danger: #C62828;    /* Rojo aprobado */
  --status-warning: #A65100;   /* Corrección WCAG AA: ámbar oscuro legible */
}

@media (prefers-color-scheme: dark) {
  :root {
    /* MODO OSCURO (Automático) */
    --bg-base: #121212;
    --bg-surface: #222226;     /* Corrección: resalta las cards y sostiene el contraste */
    --text-primary: #FFFFFF;   /* Corrección: Blanco absoluto para máxima legibilidad */
    --text-secondary: #B3B3B7; /* Corrección WCAG AA: ratio seguro de 5.1:1 */
    --border-color: #323238;
    
    --primary-color: #5C9EFF;  /* Corrección WCAG AA: azul vibrante seguro (4.6:1) */
    --primary-hover: #80B3FF;
    
    /* Semánticos Oscuro */
    --status-success: #81C784;  /* Verde pastel aprobado */
    --status-danger: #FF8A65;   /* Coral pastel aprobado */
    --status-warning: #FFB74D;  /* Amarillo pastel aprobado */
  }
}
